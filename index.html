Architecture

Designed for availability and isolation.

Internet traffic enters through an Application Load Balancer in public subnets. Application instances run in private subnets across two availability zones, with RDS configured for Multi-AZ deployment.

AWS Resources

Core infrastructure

The Terraform configuration provisions the network, routing, compute, database, access path, and traffic distribution required by the project.

Network

VPC, two public subnets, two private subnets, Internet Gateway, NAT Gateway, and route tables.

Compute & traffic

Application Load Balancer, target group, listener, launch template, and Auto Scaling Group.

Data & access

Multi-AZ MySQL RDS, database subnet group, security groups, and a bastion host for SSH entry.

Project outcomes

What the setup demonstrates

  • Multi-AZ fault tolerance
  • No direct public access to app servers
  • Secure SSH path through a bastion host
  • Auto scaling under load
  • Database failover
  • Internet and private routing separation
